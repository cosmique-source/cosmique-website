Pricing

The server is free, forever. The iOS app has a generous free tier and an optional Pro unlock. That's it.

The server

FreeForever — open source
$ docker run … orbit/server
  • Run it on your NAS, home server, a Raspberry Pi, or a miniPC.
  • No account required. No trial countdown. No licence key.
  • No telemetry unless you turn it on.
  • Cloud-side code is open — audit it yourself.

Optional

Free tier. Remote access is included with Pro. Accounts are free; encrypted metadata backup is included; heavy users with hardware endpoints may see a paid relay tier later.
